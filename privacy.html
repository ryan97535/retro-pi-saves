RETRO PI SAVES

Privacy policy

Effective October 4, 2026

Retro Pi Saves is a personal save synchronization utility maintained by ryan97535. This policy describes the utility and its informational website.

Data accessed and its purpose

The utility reads and writes selected game save files in the owner's configured Google Drive save folder. It stores save contents, filenames or game identifiers, emulator core identifiers, device labels, file sizes, timestamps, checksums, and version relationships. These are used to synchronize game progress, verify files, identify conflicts, and recover older versions.

The current OAuth scope allows broad access to Drive files. The application is configured to operate in the designated save folder, but this configuration does not limit the scope of Google's authorization. The utility does not intentionally process unrelated Drive documents.

Credentials, storage, and sharing

Google OAuth tokens and client configuration are stored on the owner's devices and used by rclone to connect directly to Google Drive. Save versions and metadata are stored on those devices and in the owner's Drive. Transfers to Google use HTTPS. The utility does not apply additional encryption to local saves or archives.

The utility has no separate developer-operated server that receives save data. Google processes cloud data to provide Drive services. Google user data is not sold, used for advertising, or used to train AI models by this utility. The utility's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and your controls

Save archives are retained until the owner deletes them. There is no automatic expiration of archived versions. The owner can stop the Pi service and Windows scheduled task, revoke Google access through the Google Account's third-party connections settings, and manually remove local archives or cloud files.

Revoking access stops future authorized cloud operations; it does not delete existing local saves or archives. Deleting a cloud archive does not automatically delete copies on other devices. Before permanently deleting data, stop synchronization on all devices and remove each copy you intend to delete.

This website and contact

This static website does not include advertising, analytics scripts, or a Google sign-in form. GitHub Pages provides hosting and may process connection information such as IP addresses under GitHub's privacy statement.

For questions about this personal utility or policy, contact the maintainer through the ryan97535 GitHub profile. Policy updates will be published on this page with a revised effective date.
