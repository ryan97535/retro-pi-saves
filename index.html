PERSONAL SAVE SYNC

Retro Pi Saves

Keep your game progress with you.

Retro Pi Saves is a personal utility maintained by ryan97535. It synchronizes selected emulator battery saves between a Batocera Raspberry Pi and a Windows PC through the owner's Google Drive.

Play locally. Sync when connected.

Each device keeps a local save and archives changed versions. When an internet connection is available and the emulator is closed, the utility uploads and downloads save versions directly through Google Drive.

If devices change a save independently, both versions are retained before the version with the newer save timestamp becomes active. An archived version can be restored manually. Timestamps do not measure in-game progress.

Why Google Drive access is needed

The desktop utility uses Google OAuth and rclone to access the configured save folder, upload save data and version metadata, and download saves onto the owner's devices. Its current OAuth scope grants broad Drive file access; the utility is configured to operate within the designated save folder. The folder setting does not narrow the underlying OAuth permission.

This website is informational. It does not provide a sign-in form, receive saves, or store Google credentials. The utility is intended for the owner's personal use, and is not a public account service.
